Leonida Cover Forge — a multi-panel GTA 6 cover maker: load up to four of your photos, crop and position each one, pick from four poster layouts and five colour grades, set the title, subtitle and ribbon, and export the cover as a PNG in 1080×1080, 1080×1350 or 1920×1080. Four synthetic sample scenes ship with the app, so it works with one click and no upload. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or hand the app in with `MAKEFUN_OUTPUT_DIR=out node main.ts`, which stages `app/` and `screenshots/` into `out/` and writes `out/dossier.json`.
